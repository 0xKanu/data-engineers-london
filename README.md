# Data Engineers London

Community website for [Data Engineers London](https://www.meetup.com/data-engineers-london/) (2,000+ members). Built with Astro, styled with Tailwind CSS, hosted on Firebase.

## Tech Stack

- **Framework:** Astro (static site, TypeScript)
- **Styling:** Tailwind CSS v4
- **Content:** Markdown via Astro Content Collections
- **Hosting:** Google Firebase Hosting
